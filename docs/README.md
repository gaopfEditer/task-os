# 文档资源（docs/）

专题长文存放在本目录，与 `info/resources.md`（链接收藏，由资讯创作官维护）**分开**，供任务规划、能力对齐时查阅。

## 入库规则

1. 将专题正文以 `.md` 放在 `docs/` 下（文件名建议与标题一致，避免特殊字符）。
2. 在 `docs/index.md` 的索引表中**新增一行**：标题 | 路径 | 摘要 | 标签 | 更新时间。
   - **路径**：相对仓库根目录，如 `docs/软件开发能力边界专题.md`。
   - **摘要**：一句话说明专题用途。
   - **标签**：以 `#` 开头的标签，空格分隔，便于看板筛选。
   - **更新时间**：正文有实质修订时改为当天日期（`YYYY-MM-DD`）。
3. 提交并推送到 `main`；网页看板「文档资源」页会自动读取（合并后点「刷新」即可）。

## 查看方式

- 看板：<https://gaopfediter.github.io/task-os/#docs> — 浏览索引、搜索/按标签筛选、点开标题阅读正文（只读）。
- GitHub：直接打开 `docs/` 下对应文件或 `docs/index.md`。

## 不要做的事

- 不要把专题正文写进 `info/resources.md`。
- 不要在本模块存放资讯创作流水或外链清单（那些走 `info/`）。
