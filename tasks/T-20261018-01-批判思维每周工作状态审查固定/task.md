## 目标
批判思维大师**每周一次**检查各 agent（任务管家、代码大师、软件接单、出海大师等）的工作状态：可随机抽查，或按职责 / 已执行内容审查，并给出建议；**不越权改他人工作区**（ops-master、content-os 等由对应 bot 维护）。

## 成功标准（每周一轮）
- [ ] 任务管家在**每周五约 20:00（Asia/Shanghai）**例行触发本轮审查
- [ ] 批判思维大师完成对各相关 agent 的状态审查（抽查或按职责），输出可执行建议
- [ ] 结果汇总为供用户查看的 **「每周重点」** 摘要（写入当周 `weekly/` 或链到任务 `review.md` / 看板可见处）
- [ ] 任务管家收口：索引与状态同步文档中可追溯；未勾项在晚汇总 / 周巡中跟进

## 范围
- **做**：读看板、`daily/`、`weekly/`、任务 execution、公开 docs；批判性评估与建议；「每周重点」落盘
- **不做**：代替各 bot 写稿 / 写代码 / 出海取舍拍板；擅自改他人专属目录内容

## 与任务管家周巡
- 周五约 20:00 触发批判周检；**周日约 21:00** 任务管家周巡保留，可衔接（周五审查结论供周末前后汇总参考）。
