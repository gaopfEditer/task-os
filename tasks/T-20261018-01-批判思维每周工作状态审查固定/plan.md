# 计划

## 背景
2026-10-18 看板落盘：将「批判思维大师每周检查各 agent 工作状态」定为**固定例行**，避免仅依赖口头「一周后复评」。

## 节奏（固定）
| 时点 | 谁 | 做什么 |
|------|-----|--------|
| 每周五约 20:00（Asia/Shanghai） | 任务管家 | 触发本轮批判周检（@批判思维大师或等价派单） |
| 周五触发后同一自然日或周末内 | 批判思维大师 | 审查各 agent 状态，写建议 |
| 收口 | 任务管家 | 「每周重点」入库、必要时更新 `docs/任务管家视角-状态同步-*.md` 协作规矩节 |
| 每周日约 21:00（Asia/Shanghai） | 任务管家 | 周巡（保留）；可引用周五「每周重点」 |

## 审查对象（示例，可扩展）
- 任务管家：排期、看板是否 15 分钟内更新、验收线是否唯一
- 代码大师：PR / 技术债与群拍板一致性
- 软件接单：邮箱异步任务与边界
- 出海大师：接单 / 双轨与 ops-master 产出是否对齐看板

## 产出模板（每周重点，建议条目）
1. 本周各 agent 一句话状态
2. 抽查或按职责发现的问题（附证据路径）
3. 建议与优先级（不代执行）
4. 待主人 / 任务管家拍板项（如有）
