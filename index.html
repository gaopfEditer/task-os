    设置：GitHub 令牌

    在网页上保存 daily/ 日记需要一个 GitHub 细粒度个人访问令牌（fine-grained personal access token）。只看不改不需要令牌。

    1. 打开 https://github.com/settings/personal-access-tokens/new
    2. Resource owner 选 gaopfEditer；Repository access 选 Only select repositories → task-os
    3. Permissions → Repository permissions → Contents 设为 Read and write（其他保持默认）
    4. 生成后复制以 github_pat_ 开头的令牌，粘贴到下面并保存

    令牌只保存在当前浏览器的 localStorage 中，只会发送给 GitHub API（api.github.com），不会写进仓库。在公用设备上用完请点「清除」。
